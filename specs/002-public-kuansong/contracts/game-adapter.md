# 子游戏接口 v1

每个游戏的 index.cjs 导出 apiVersion（1）、id、name 和 recommend(input, random?)。直接运行时从标准输入读取一个 UTF-8 JSON 对象，将结果写到标准输出。无效输入写明错误并返回非零退出码。

输入包含 players（人数）、self（从零开始的座位）、options（可选游戏规则）、observations（按接收顺序的观察数组）。当前 22 个入口的规则以 games/internal/catalog.cjs 为准。省略规则时使用清单的首个允许值。目录名将 ID 中的下划线换成连字符，模块仍导出原始 ID。每项观察包含 text，可附带 private 布尔值。公开观察和本人的私信由调用方筛选。适配器可按游戏文档扩展结构化观察字段。random 可在调用模块时注入确定性随机源。

输出为 null（当前无动作）或对象，字段为 text、channel（private 或 group）、why。动作由宿主基于实时路由和规则再次校验后发送。每次调用须使用独立状态。宿主负责可信身份、完整性、顺序、去重、可行动时机和发送回执。

差值投标接受 2 人、金币 30、回合数 9，观察内容使用已结算行文本。仓库示例演示开局建议。连续观察应提供累积的结算行。
