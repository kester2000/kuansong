# 功能规格 · 宽松框架与漫漫长夜决策器

## 用户场景与独立验收

### US1 · 通过 QQ 参加一局（P1）
群友通过宽松指令查询能力、加入或退出漫漫长夜。框架识别受信任 LGTBot 的公告，核验群、身份、人数、规则和对局，接收当局公开消息及本账号收到的相关私信；经校验后在当前群或向受信任裁判发送动作。验收覆盖公开与私聊的收发、非信任来源、不同群串局、管理员指令、重复收件和断线补录。

### US2 · 替换决策器（P1）
开发者用相同录制输入分别驱动内置漫漫长夜策略和外部程序，例如 C++ 命令行程序。框架为每次决策提供同一版本的玩家可见观察、合法目标和运行预算。验收覆盖可发送建议、无动作、非法建议、超时、进程崩溃和协议不兼容。

### US3 · 归档与复盘（P2）
运行者可以按局查看收件、有效观察、建议、发送结果、结算和运行报告。验收以合成事件重放，核对档案顺序、证据引用和回执状态。报告生成或发布失败时保留原始档案并允许重试。

## 功能需求

- FR-001 框架通过 SnowLuma 的 OneBot v11 接收群聊和私信事件，按可信账号、群、局和时序过滤、标准化、去重，并按可用历史能力补录。
- FR-002 框架负责帮助、加入与退出、战绩、管理员单机及重置的路由与权限。战绩可在未入局时查询。人数越界、未知规则或缺失必需规则时拒绝入局。游戏注册表仅登记漫漫长夜。适配器声明支持规则并判断游戏阶段、允许动作和可用观察。
- FR-003 框架把当前玩家当时可见的私信和相关公开观察交给决策器。加入握手和身份核验由框架完成。观察不足、身份不明或范围歧义时暂停。
- FR-004 决策器按版本化契约返回动作建议或等待。框架重新检查当前状态、建议目标和规则，记录意图后通过 SnowLuma 发送，保存回执或待核对状态。重复建议、过期结果、发送结果未知都不能触发盲目补发。
- FR-005 框架负责资料采集、对局归档、运行日志、报告产出调度及发布权限。适配器负责游戏结算解释、地图与策略报告内容。私聊、附件、原始数据和生产配置保存在私有目录。图像证据保留私有路径与哈希。
- FR-006 内置与外部决策器遵循同一语义契约。应能在没有 QQ 连接时使用合成或脱敏的固定观察调用决策器。

## 可测量验收

- SC-001 同时重放两局及无关私信，所有建议与回执只能归入对应的局。帮助和入局许可只显示漫漫长夜。
- SC-002 内置策略与一个 C++ 样例通过同一套协议验证；每个超时、非法目标、无动作与重复响应样例产生零条额外 QQ 消息。
- SC-003 从收件到结算的固定样例可完整归档，可从报告追溯原始事件和发送状态，报告重试不会补发游戏动作。
- SC-004 旧实现的既有漫漫长夜回归通过，单机入口可独立运行。
